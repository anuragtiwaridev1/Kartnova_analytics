# KartNova — End-to-End Retail Analytics (Python · SQL · Power BI/DAX)

A portfolio-grade analytics project on an Indian omnichannel e-commerce retailer (**Jan-2023 → Dec-2025**: 9,000 customers · 29,107 orders · 62,700 order lines · 5,503 returns · ₹26.2 Cr net revenue).
The **same dataset** is analysed three independent ways — **Python**, **SQL**, **Power BI + DAX** — and the headline numbers are reconciled across all three.

> **Transparency:** the dataset is **synthetic** (generated by `data_generation/generate_dataset.py`, seeded for reproducibility) with realistic dynamics:
> festive seasonality, churn, category margins/returns, bundles, regional delivery gaps and deliberately injected data-quality defects.
> State this openly on your resume/interview ("simulated retail dataset") — the value is the methodology, not the data. The code runs unchanged on real data with the same schema.

## Quick start

```bash
pip install -r requirements.txt
python run_all.py                  # regenerates everything (~1 minute); or run any script individually
```
* **SQL:** open `sql/retail.db` in any SQLite client, or read `sql/results/*.csv`.
* **Power BI:** follow `powerbi/README_DAX.md` §1 (30–45 min to build; DAX validated by reconciliation queries).

## Resume bullets (copy/adapt — keep the "simulated dataset" disclosure in the project line)

**KartNova Retail Analytics — End-to-End Analytics Project (Python, SQL, Power BI/DAX)** · *simulated e-commerce dataset, 9K customers / 29K orders*
* Designed and delivered a three-layer analytics solution (Python, SQL, Power BI/DAX) on one cleaned star-schema dataset; **reconciled KPIs to the rupee across all three tools** and profiled, fixed and logged 9 types of data-quality defects with automated SQL integrity checks.
* Built **customer analytics** — RFM + K-Means segmentation, cohort retention, and a leakage-safe **churn model (ROC-AUC 0.83)** that ranks customers by revenue-at-risk; showed top-4 risk deciles capture 54% of churners.
* Quantified **marketing efficiency** (CAC, 12-month LTV, payback) by channel, revealing Paid Search at 2.5× LTV:CAC vs 12.5× for Referral and recommending budget reallocation.
* Used **hypothesis testing** to show deep discounts add no volume (Spearman ρ≈0, p=0.29) yet cut margin; built a DAX what-if model estimating **+₹84 L (+10.9%) gross-profit upside** from a 10% discount cap.
* Authored ~80 **DAX measures** (fiscal time intelligence, Pareto/ABC, cohort matrix, dynamic metric switcher, RLS) on a star schema with Power Query parameterisation; wrote DAX Query View tests for model validation.
* Produced a **6-month revenue forecast** selected via rolling-origin backtesting (MAPE 14.5% vs 30.5% baseline) and a prioritised, quantified recommendation list for leadership.
